Les courbes de perception du prix

Comment lire ces calculs

Les quatre prix doivent respecter : trop bas ≤ bonne affaire ≤ cher ≤ trop cher. Les prix incomplets, non numériques, négatifs ou désordonnés sont exclus uniquement de cette analyse, et restent comptés dans les autres questions renseignées. Les courbes affichent les proportions : seuil trop bas ≥ prix testé ; seuil bonne affaire ≥ prix testé ; seuil cher ≤ prix testé ; seuil trop cher ≤ prix testé.

Le point d’égal rejet est l’intersection des courbes « trop bas » et « trop cher », interpolée entre les seuils observés. Un plateau est affiché comme une plage. Ce point n’optimise ni bénéfice, ni chiffre d’affaires. Il n’est affiché qu’à partir de 30 quadruplets cohérents, une convention de prudence de notre site sans garantie de représentativité ou de précision.

Intention générale d’achat

« Favorable » désigne les scores 4 ou 5 pour l’intention générale, et « Élevée » ou « Très élevée » pour les trois probabilités. Les prix sont présentés dans un ordre croissant aux mêmes personnes. Ce protocole peut produire un effet d’ordre : les réponses ne constituent pas des achats observés ni des prévisions de ventes.

Vérification de la mémorisation

Les visuels diffèrent entre les versions : un écart observé peut concerner l’ensemble de la présentation. Il ne démontre pas à lui seul l’effet du grammage. La répartition aléatoire du code n’est pas une garantie contre les participations multiples ou les déséquilibres d’effectifs.

7. Croiser les variables

Par exemple : sport × intention d’achat, version × probabilité à 4,99 €, âge × consommation de glaces, ou culpabilité × habitudes protéinées.

Les petites cellules restent visibles pour explorer les réponses du groupe, avec leurs effectifs. Un croisement portant sur une ou quelques personnes ne permet aucune généralisation.
